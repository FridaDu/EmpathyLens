**Tier 3 专用检查清单（每次执行前过一遍）**：

- [ ] 已登录 DeepSeek 后台，确认实时余额
- [ ] 已登录 OpenAI 后台，确认实时余额
- [ ] 已登录 Anthropic 后台，确认实时余额
- [ ] 三家余额合计 ≥ 本次预估成本（`run_judge.py` 启动时会打印）的 1.5 倍
- [ ] `PRICING` 常量已用近期真实账单校准过（不是仍然沿用未校准的占位符）
- [ ] 已规划分 2-3 天分批执行，不打算一次性跑完
- [ ] 已确认 `--daily-cap-eur` 设置合理（不会被单日消耗打满导致中途拒绝执行）
